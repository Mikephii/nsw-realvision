# Valuer General NSW reference documents

The official documents for the bulk Property Sales Information files, as published by the Valuer
General NSW. They are kept here unmodified so the format reference stays available alongside the
parser.

| Document | What it covers |
|---|---|
| [Current_Property_Sales_Data_File_Format_2001_to_Current.pdf](Current_Property_Sales_Data_File_Format_2001_to_Current.pdf) | Field-by-field schema of the current format (records A, B, C, D, Z) |
| [Archived_Property_Sales_Data_File_Format_1990_to_2001_V2.pdf](Archived_Property_Sales_Data_File_Format_1990_to_2001_V2.pdf) | Schema of the archived 1990 to 2001 format |
| [Property_Sales_Data_File_-_Data_Elements_V3.pdf](Property_Sales_Data_File_-_Data_Elements_V3.pdf) | Plain-English description of every data element |
| [Property_Sales_Data_File_-_Instructions_V2.pdf](Property_Sales_Data_File_-_Instructions_V2.pdf) | How to open the files, accuracy notes and the data licence |
| [Property_Sales_Data_File_District_Codes_and_Names.pdf](Property_Sales_Data_File_District_Codes_and_Names.pdf) | District code to council name |
| [Property_Sales_Data_File_Zone_Codes_and_Descriptions_V2.pdf](Property_Sales_Data_File_Zone_Codes_and_Descriptions_V2.pdf) | Zone codes, pre-2011 and LEP |
| [Property_Sales_Information_Data_Files_User_guide.pdf](Property_Sales_Information_Data_Files_User_guide.pdf) | The full user guide, with all of the above as appendices |
