# NSW RealVision webapp

The TanStack Start app: dashboards, the growth heatmap, the property map and custom areas. It reads the
DuckDB database the ETL in [`../scripts`](../scripts) builds.

See the [root README](../README.md) to get started, [docs/self-hosting.md](../docs/self-hosting.md) to run
it on a server, and [docs/architecture.md](../docs/architecture.md) for how it fits together.

```sh
pnpm install
pnpm dev        # http://localhost:3000
pnpm test
```
